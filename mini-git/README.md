# Mini Git Version Control System in C++ (Semester project)

## Overview

A simplified Git-like Version Control System developed in C++ using fundamental Data Structures and Algorithms. The project simulates version control operations such as commits, history management, and file tracking through custom data structure implementations.

## Features

* Create and manage commits
* Maintain commit history
* Search versions efficiently
* Track project changes
* Console-based user interface

## Data Structures Used

### Stack

Used for version history navigation and rollback operations.

### Queue

Used for processing commit-related operations in sequence.

### Priority Queue

Used to manage commits based on priority and ordering.

### Binary Search Tree (BST)

Used for efficient searching and organization of commit records.

## Technologies

* C++
* File Handling
* Data Structures and Algorithms
* Function-Based Programming Approach
